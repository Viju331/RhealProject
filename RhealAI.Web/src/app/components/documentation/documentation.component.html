Choose the Right AI Provider

OpenAI (128K tokens) for large projects, GitHub Models (free) for small to medium projects



Token Limits

GitHub Models: 8-16K tokens (free). OpenAI: 128K tokens (paid). Choose based on project size.



Language-Specific Analysis

The system automatically applies language-specific rules. SQL files won't get C# suggestions and vice versa.



Real-Time Progress

Watch the progress bar for detailed status through all 7 analysis steps with SignalR real-time updates.

Clean Architecture

The system understands Clean Architecture patterns and detects violations like business logic in controllers.
